Privacy Policy

Last updated: March 2026

Overview

UGD Upwork Research Tool ("the Extension") is a private tool used exclusively by Abhishek Bhambhana and authorized team members for Upwork profile research and optimization. It is not available to the general public.

Data Collected

The Extension collects the following data from publicly visible Upwork pages:

  • Freelancer profile titles, skills, rates, and overview text (publicly visible on Upwork)
  • Job post titles, required skills, and budget ranges (publicly visible on Upwork)

How Data Is Used

All collected data is used solely for:

  • Internal keyword research and frequency analysis
  • Profile optimization recommendations for our team's Upwork accounts

Data Storage

Data is stored locally in your browser using Chrome's chrome.storage.local API. No data is transmitted to any external server, database, or third party. Data remains on the user's device only.

Data Sharing

We do not sell, share, or transmit any collected data to third parties. The Extension operates entirely offline after page load.

Permissions Used

  • storage — Save collected data locally in Chrome
  • activeTab — Read the currently open Upwork page
  • scripting — Execute collection scripts on Upwork pages
  • tabs — Navigate between pages during automated collection
  • upwork.com host permission — Required to access Upwork pages only
